# RequestSystem

**Автор:** Джавадов Ильхам, группа ИСИП-307  
**Дисциплина:** Технологии разработки программного обеспечения

## Назначение

RequestSystem — внутренняя система обработки заявок для организации. Автоматизирует приём, регистрацию, обработку и контроль исполнения заявок.

## Основные функции

- Создание и регистрация заявок
- Назначение исполнителей
- Управление статусами заявок
- Комментарии и вложения
- Контроль сроков (SLA)
- Отчёты по заявкам и загрузке исполнителей
